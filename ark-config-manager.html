📖 使用帮助

🚀 快速开始
  1. 用 Chrome 或 Edge 打开本页面
  2. 点击 📂 打开文件 加载 GameUserSettings.ini 或 Game.ini，或直接拖拽文件到窗口
  3. 左侧分类栏浏览参数，或搜索框输入关键词筛选
  4. 双击参数行或点 ✏️ 编辑，修改后点弹窗里的保存
  5. 改完后点右上角 💾 保存 → 确认修改 → 写入文件
📋 两个配置文件
文件加载顺序管什么
GameUserSettings.ini先加载倍率、模式（PVE/PVP）、规则（腐坏/洞穴）、密码、RCON
Game.ini后加载（覆盖前者）属性成长、繁殖、伤害/抗性、细分经验、功能开关
⚠ Game.ini 会覆盖 GameUserSettings.ini 中同名设置，注意不要设冲突的值。
✏️ 编辑参数
  • 数字 → 数字输入框，自动校验范围
  • 布尔 → True / False 单选按钮
  • 字符串/密码 → 文本输入框
  • 点击弹窗外不会关闭，必须点取消或保存；ESC 键也可关闭
  • 行尾 ↩ 按钮可快捷重置单个参数为默认值
💾 保存 / 下载 / 备份 的区别
按钮作用
💾 保存弹确认窗列出修改 → 确认后写回原文件
📥 下载导出当前配置为新文件（含未保存修改），不覆盖原文件
📦 备份同上，但文件名带时间戳，方便保存多版本
↺ 恢复默认值所有参数重置为官方默认 → 弹确认窗 → 保存
🖥️ 服务器部署
  1. 切换到 🖥️ 服务器部署 tab
  2. 填写服务器路径（ARK Survival Ascended Dedicated Server 的根目录）
  3. 填写服务器名称、最大玩家数
  4. 高级设置：小白不用改，默认即可
  5. 勾选要启用的 Mod
  6. 密码：点击提示文字跳转到 GameUserSettings.ini → 网络与管理 中设置
  7. 点击 🚀 生成启动工具文件
  8. 工具会提示选择服务器目录自动写入 INI 文件，并下载 Start_ARK_Server.bat
  9. 双击 bat 文件启动服务器
文件放置位置：
GameUserSettings.ini / Game.ini → ShooterGame\Saved\Config\WindowsServer\
Start_ARK_Server.bat → 任意位置（bat 内置 cd 命令自动跳转）
🔌 Mod 搜索

切换到 🔌 Mod搜索 tab，输入关键词即可搜索 6700+ CurseForge Mod。点击 📋 复制ID 复制 Mod ID。

需要 mods-data.js 与 HTML 在同一目录下才有全量数据，否则使用内置 32 个精选 Mod。

💡 小技巧
  • 选中分类后，部分分类会显示联动说明（如采集倍率的公式关系）
  • 选 仅已修改 可快速定位改动过的参数
  • 模版下拉框可下载官服或高倍率预设作为起点
  • 切换 tab 或刷新页面时会提示未保存的修改
  • 可 💾 保存方案 / 📂 加载方案 备份整个部署配置
