# 🦖 ARK ASA 服务器配置管理器

方舟生存飞升 (ARK: Survival Ascended) 服务器配置文件可视化管理工具 —— 纯前端单文件 HTML，双击即用。

## 功能一览

| 功能 | 说明 |
|------|------|
| 📋 配置文件管理 | 加载、编辑、保存 `Game.ini` 和 `GameUserSettings.ini` |
| 🔍 参数可视化 | 200+ 服务器参数，分类筛选、搜索、排序、中文说明 |
| ✏️ 类型化编辑 | 数字用数字框、布尔用单选按钮、字符串用文本框，自动校验 |
| 📋 保存确认 | 保存前弹窗列出所有改动（原值 → 新值），逐条确认 |
| 📦 配置备份 | 一键下载带时间戳的备份文件，方便存档多个版本 |
| 🔄 恢复默认值 | 一键将所有参数重置为官方默认值 |
| 📥 模版下载 | 内置官服 / 高倍率两种预设配置 |
| 🔌 Mod 搜索 | 内置 6700+ CurseForge Mod 全量数据，按名称/分类/ID 搜索 |
| 🖥️ 服务器部署 | 生成启动 bat 文件、选择地图/Mod/端口，一键导出部署包 |
| ⚠️ 未保存提示 | 切换标签页或刷新页面时提示有未保存的修改 |
| 💡 分类联动说明 | 每个参数分类附带公式和配置建议（如采集倍率叠加关系） |
| 🌓 主题切换 | 暗色/亮色主题一键切换 |
| 📂 拖拽加载 | 支持拖拽 .ini 文件到窗口直接加载 |

## 环境准备

### 日常使用

只需浏览器，无需安装任何东西：

- **Chrome** 或 **Edge**（推荐，支持直接保存回原文件）
- 双击 `ark-config-manager.html` 即可打开

### 更新 Mod 数据（偶尔）

需要 Node.js 环境来运行数据拉取脚本：

1. **安装 Node.js** ≥ 18（已安装可跳过）

   | 系统 | 方式 |
   |------|------|
   | Windows | [nodejs.org](https://nodejs.org) 下载 LTS 安装包 |
   | macOS | `brew install node` 或 [nodejs.org](https://nodejs.org) |
   | Linux | `sudo apt install nodejs` 或 [nodejs.org](https://nodejs.org) |

   ```bash
   node -v   # 确认版本 ≥ v18.0.0
   ```

2. **获取 CurseForge API Key**（免费）

   访问 [console.curseforge.com](https://console.curseforge.com/) 注册账号 → 创建应用 → 复制 API Key

3. **运行拉取脚本**

   ```bash
   cd d:\vsCode\my-ark-asa

   # Windows PowerShell:
   $env:CURSEFORGE_API_KEY="你的API Key"
   node fetch-mods.cjs

   # Windows cmd:
   set CURSEFORGE_API_KEY=你的API Key && node fetch-mods.cjs

   # Linux / Mac:
   export CURSEFORGE_API_KEY=你的API Key && node fetch-mods.cjs
   ```

   API Key 只存在于终端的环境变量中，**不会写入任何文件**，用完即销毁。

## 使用指南

### 第一步：加载配置文件

有三种方式加载你的 INI 文件：

| 方式 | 操作 |
|------|------|
| 打开按钮 | 点击右上角 **📂 打开文件**，选择 `.ini` 文件 |
| 拖拽 | 直接把 `.ini` 文件拖到浏览器窗口 |
| 模版下载 | 从工具栏下拉框选择官服或高倍率模版，下载后加载 |

工具会自动识别文件类型（含 `[ServerSettings]` 的是 GameUserSettings.ini，否则是 Game.ini），切换到对应 tab。

> 如果你还没有配置文件，可以先下载模版作为起点。

### 第二步：理解两个配置文件

页面顶部有两张说明卡片，解释两个文件的关系：

| 文件 | 加载顺序 | 管什么 |
|------|----------|--------|
| **GameUserSettings.ini** | 先加载 | 倍率（经验/驯服/采集）、模式（PVE/PVP）、规则（腐坏/洞穴）、密码、RCON |
| **Game.ini** | 后加载，可覆盖前者 | 属性成长、繁殖、伤害/抗性、细分经验、功能开关 |

⚠️ **Game.ini 会覆盖 GameUserSettings.ini 中同名设置**，修改时注意不要在两边设冲突的值。

### 第三步：浏览和搜索参数

- **左侧分类栏**：按功能分类（经验倍率、采集与制作、繁殖系统等），点击切换
- **搜索框**：输入参数名或中文说明即时筛选
- **"仅已修改"**：只显示当前值与默认值不同的参数
- **表头排序**：点击"参数名"或"当前值"表头排序
- **分类联动说明**：部分分类（如采集与制作、繁殖系统）选中后会显示参数间的计算公式

### 第四步：编辑参数

**双击**参数行或点击 ✏️ 按钮打开编辑弹窗：

- **数字参数** → 数字输入框，自动校验范围
- **布尔参数** → True / False 单选按钮
- **字符串/密码** → 文本输入框

修改后点 **保存**（弹窗内的保存）→ 表格立即显示新值，状态栏显示"有未保存的修改"。

> 点击弹窗外不会关闭，必须点取消或保存。ESC 键也可以关闭。

也可以点击行尾的 **↩** 按钮，快捷重置单个参数为默认值。

### 第五步：保存到文件

点击右上角 **💾 保存**：

1. 弹出确认窗，列出所有修改项（参数名、说明、原值、新值）
2. 逐条检查无误后，点 **✅ 确认保存**
3. 写入原文件（需 Chrome/Edge 支持 File System Access API）

> 状态栏的黄色圆点表示有未保存的修改，保存后变为绿色。

### 其他操作

| 按钮 | 作用 |
|------|------|
| **📥 下载** | 导出当前配置为 `.ini` 文件（含未保存的修改） |
| **📦 备份** | 同上，但文件名带时间戳（如 `GameUserSettings_backup_2026-07-24T14-30-00.ini`），方便存档多版本 |
| **↺ 恢复默认值** | 将所有参数重置为官方默认值，重置后弹出保存确认窗 |
| **📖 配置说明** | 展开两个配置文件的详细说明卡片 |
| **🌓 主题切换** | 暗色/亮色模式切换 |

---

### 服务器部署

切换到 **🖥️ 服务器部署** 标签页：

1. **基本配置**：设置服务器路径、名称、最大玩家数
2. **高级设置**（点击展开）：端口、BattleEye、RCON、跨平台、集群 ID
   > 💡 **小白不用改，默认即可。** 这些是给开多个服务器或需要自定义端口的人用的。
3. **Mod 选择**：从 Mod 列表中勾选要启用的 Mod
4. **密码**：点击提示文字跳转到 GameUserSettings.ini → 网络与管理 中设置
5. 点击 **🚀 生成启动工具文件**：
   - 自动下载 `StartServer.bat` 到本地
   - 同时提示选择服务器目录，将 `GameUserSettings.ini` 和 `Game.ini` 写入对应位置

💡 还可以 **💾 保存方案** / **📂 加载方案** 来保存和恢复整个部署配置（JSON 格式）。

#### 文件放置位置

| 文件 | 服务器上的路径 |
|------|---------------|
| `GameUserSettings.ini` | `ShooterGame\Saved\Config\WindowsServer\` |
| `Game.ini` | `ShooterGame\Saved\Config\WindowsServer\` |
| `StartServer.bat` | 任意位置（bat 内置 `cd /d` 自动跳转到服务器 exe 目录，放桌面即可） |

> 点击「生成启动工具文件」时，工具会提示选择服务器目录并自动写入 INI 文件；bat 文件下载到浏览器默认下载目录，放哪里都行。

---

### Mod 搜索

切换到 **🔌 Mod搜索** 标签页：

- 输入关键词搜索 6700+ CurseForge Mod
- 显示 Mod 名称、分类标签、简介、ID
- 点击 **📋 复制ID** 复制 Mod ID 到剪贴板
- 支持分页浏览

> 确保 `mods-data.js` 与 HTML 在同一目录。如果没有这个文件，页面使用内置的 32 个精选 Mod 列表。

## 文件说明

| 文件 | 说明 |
|------|------|
| `ark-config-manager.html` | ⭐ 主程序，双击即用 |
| `mods-data.js` | Mod 全量数据（6700+ 条），HTML 通过 `<script src>` 加载 |
| `fetch-mods.cjs` | 数据拉取脚本，从 CurseForge API 更新 `mods-data.js` |
| `package.json` | Node.js 项目元数据 |

## 技术栈

| 层 | 技术 |
|----|------|
| UI 框架 | Vue 3 (CDN, `vue.global.prod.js`) |
| 样式 | CSS Variables + 暗色/亮色主题 |
| INI 解析 | 手写解析器（支持注释、Section、Key=Value） |
| 文件读写 | File System Access API（Chrome/Edge） |
| 数据拉取 | Node.js + CurseForge REST API |
| 运行环境 | 纯浏览器端，无需服务器 |
