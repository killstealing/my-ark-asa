# 🦖 ARK ASA 服务器配置管理器

方舟生存飞升 (ARK: Survival Ascended) 服务器配置文件可视化管理工具 —— 纯前端单文件 HTML，双击即用。

> 💡 **搭一个方舟服务器没有想象的那么难！** 总共就三步：
> **⓪ 安装服务器** → **① 配置参数** → **② 启动服务器**，就这么简单。

## 前置条件：安装服务器

在使用本工具之前，需要先在 Steam 中安装 ARK 专用服务器（只需一次）：

1. 打开 **Steam**
2. 点击左上角「库」旁边的下拉箭头，把"游戏"切换为 **「工具」**
3. 在列表中找到 **ARK: Survival Ascended Dedicated Server**
4. 点击 **安装**，等待下载完成

> 📁 安装完成后，默认路径：`C:\Program Files (x86)\Steam\steamapps\common\ARK Survival Ascended Dedicated Server\`

## 使用指南

### 第一步：加载配置文件

**拖拽** `GameUserSettings.ini` 或 `Game.ini` 文件到浏览器窗口即可加载。

> 📁 文件位置：`ARK Survival Ascended Dedicated Server\ShooterGame\Saved\Config\WindowsServer\`
>
> 如果还没有配置文件，可以先从工具栏下拉框下载**官服模版**或**高倍率模版**作为起点。

工具会自动识别文件类型，切换到对应标签页。

### 第二步：理解两个配置文件

| 文件 | 加载顺序 | 管什么 |
|------|----------|--------|
| **GameUserSettings.ini** | 先加载 | 倍率（经验/驯服/采集）、模式（PVE/PVP）、规则（腐坏/洞穴）、密码、RCON |
| **Game.ini** | 后加载（覆盖前者） | 属性成长、繁殖、伤害/抗性、细分经验、功能开关 |

⚠️ **Game.ini 会覆盖 GameUserSettings.ini 中同名设置**，修改时注意不要设冲突的值。

### 第三步：浏览和搜索参数

- **左侧分类栏**：按功能分类（经验倍率、采集与制作、繁殖系统等），点击切换
- **搜索框**：输入参数名或中文说明即时筛选
- **仅已修改**：只显示当前值与默认值不同的参数
- **表头排序**：点击"参数名"或"当前值"排序
- **分类联动说明**：选中某些分类后会显示参数间的计算公式（如采集倍率的叠加关系）

### 第四步：编辑参数

**双击**参数行或点击 ✏️ 按钮打开编辑弹窗：

| 类型 | 编辑方式 |
|------|----------|
| 数字参数 | 数字输入框，自动校验范围 |
| 布尔参数 | True / False 单选按钮 |
| 字符串/密码 | 文本输入框 |

修改后点弹窗内的**保存**，表格立即显示新值。点击弹窗外不会关闭，必须点取消或保存（ESC 键也可关闭）。

行尾 **↩** 按钮可快捷重置单个参数为默认值。

### 第五步：保存到文件

点击工具栏 **💾 保存**：

1. 弹出确认窗，列出所有修改项（参数名、说明、原值、新值）
2. 逐条检查无误后，点 **✅ 确认保存**
3. 弹出系统保存对话框，选择位置覆盖写入

> 状态栏黄色圆点 = 有未保存的修改，保存后恢复绿色。

### 其他操作

| 按钮 | 作用 |
|------|------|
| **📥 下载** | 直接导出当前配置为下载文件（含未保存修改） |
| **📦 备份** | 同下载，文件名带时间戳（如 `GameUserSettings_backup_2026-07-24T14-30-00.ini`） |
| **↺ 恢复默认值** | 将所有参数重置为官方默认值 → 弹确认窗 → 保存 |
| **📖 配置说明** | 展开/收起配置文件说明卡片 |
| **🌓 主题** | 暗色/亮色模式切换 |

### 服务器部署

切换到 **🖥️ 服务器部署** 标签页：

1. 填写**服务器路径**（ARK Survival Ascended Dedicated Server 的根目录）
2. 填写**服务器名称**、**最大玩家数**
3. 如需**多通**（跨地图传服），必须填写**集群 ID** 和**集群目录**
4. 勾选要启用的 **Mod**
5. 密码：点击提示文字跳转到 GameUserSettings.ini → 网络与管理 中设置
6. 点击 **🚀 生成启动工具文件**，直接下载 `Start_ARK_Server.bat`
7. 双击 bat 文件启动服务器

> ⚠️ **首次双击 bat 报错？** Windows 会将浏览器下载的文件标记为"来自 Internet"从而阻止运行。解决方法：**右键 .bat → 属性 → 勾选「解除锁定」→ 确定**。（这是 Windows 安全机制，不是文件有问题）

#### 多通（集群）配置须知

如果要多张地图之间互相传服：

1. 在磁盘上创建集群目录，如 `C:\serverClusters`
2. 在该目录**里面**必须再创建一个 `clusters` 子文件夹：`C:\serverClusters\clusters`
3. **集群目录**填的是父级（`C:\serverClusters`），ARK 服务器会自动找里面的 `clusters` 子文件夹
4. **所有**参与互通的服务器，集群 ID 和集群目录必须**完全一致**
5. 确保 ARK 服务器进程有**读写权限**
6. 没创建 `clusters` 子文件夹会导致传服失败！

#### 如何正确停止服务器

不要直接点右上角 ✕ 关窗口！服务器默认**每 15 分钟**自动存档一次，直接关闭会丢失最长 15 分钟的进度。

正确做法：在服务器窗口中点击右上角的 **↑ 箭头** 打开命令行 → 输入 `cheat doexit` → 按回车。服务器会先**保存存档**再优雅退出。

> 💡 也可以修改 `AutoSavePeriodMinutes` 参数来调整自动存档间隔（默认 15 分钟）。

#### 文件放置位置

| 文件 | 路径 |
|------|------|
| `GameUserSettings.ini` | `ARK Survival Ascended Dedicated Server\ShooterGame\Saved\Config\WindowsServer\` |
| `Game.ini` | `ARK Survival Ascended Dedicated Server\ShooterGame\Saved\Config\WindowsServer\` |
| `Start_ARK_Server.bat` | 任意位置（bat 内置 `cd /d` 自动跳转到服务器目录） |

### Mod 搜索

切换到 **🔌 Mod搜索** 标签页：

- 输入关键词搜索 6700+ CurseForge Mod
- 显示 Mod 名称、分类标签、简介、ID
- 点击 **📋 复制ID** 复制 Mod ID
- 支持分页浏览

> 需要 `mods-data.js` 与 HTML 在同一目录下才有全量数据，否则使用内置 32 个精选 Mod。

#### Mod 加载故障排查

**现象：** 启动服务器后 Mod 一直加载不出来。

1. **多试几次** — 偶尔网络波动导致加载失败，重启几次通常能解决
2. 如果试了十几次还不行 → 检查 `GameUserSettings.ini` 和 `Game.ini` 配置是否有误
3. 实在找不到问题 → 把两个配置文件**删掉**，重新启动服务器自动生成干净的默认配置
4. **常见坑：** 检查配置文件中是否有 `ActiveMods=` 或 `ActiveModMaps=` 参数，有的话**删掉这两行**再试（旧版本残留参数，会干扰 Mod 加载）

## 更新 Mod 数据（偶尔）

需要 Node.js 环境：

1. **安装 Node.js** ≥ 18（[nodejs.org](https://nodejs.org) 下载 LTS）

   ```bash
   node -v   # 确认版本 ≥ v18.0.0
   ```

2. **获取 CurseForge API Key**（免费）

   访问 [console.curseforge.com](https://console.curseforge.com/) 注册 → 创建应用 → 复制 API Key

3. **运行拉取脚本**

   ```bash
   # Windows PowerShell:
   $env:CURSEFORGE_API_KEY="你的API Key"
   node fetch-mods.cjs

   # Windows cmd:
   set CURSEFORGE_API_KEY=你的API Key && node fetch-mods.cjs

   # Linux / Mac:
   export CURSEFORGE_API_KEY=你的API Key && node fetch-mods.cjs
   ```

   API Key 只存在于终端环境变量中，**不会写入任何文件**。
